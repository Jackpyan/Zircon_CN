基于 LOMCN 社区开源的 [Suprcode/Zircon](https://github.com/Suprcode/Zircon)、 [choby/Zircon](https://github.com/choby/Zircon) `zh` 中文分支  
面向中文环境的二次开发版本：**完整中文本地化、跨平台 Web 管理后台、分级权限与审计体系**，并持续跟进上游修复。

> 本项目仅包含引擎源码，不包含、也不分发任何原版游戏素材。

---

## 项目关系

| 层级   | 仓库                                                    | 角色                                         |
| ---- | ----------------------------------------------------- | ------------------------------------------ |
| 上游   | [Suprcode/Zircon](https://github.com/Suprcode/Zircon) | LOMCN 社区维护的 开源引擎（2019 起），C# 全托管客户端 + 服务端实现 |
| 中文分支 | [choby/Zircon](https://github.com/choby/Zircon) `zh`  | 上游的 fork，提供中文相关改造，**本仓库的直接来源**             |
| 本仓库  | **Jackpyan/Zircon_CN**                                | 以 `zh` 分支为基础建立的独立仓库，持续二次开发                 |

**跟进策略**：上游 `master` 的持续修复、移植。
